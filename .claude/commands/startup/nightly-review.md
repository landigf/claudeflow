# /startup:nightly-review

Follow this workflow:
1. Inspect the repo and produce a nightly engineering review grounded in current code.
2. Write a concise report with quality, security, and maintainability risks.
3. Prefer the `cheap` runtime first and escalate to `deep` only for ambiguous findings.

If a required document is missing, create it from the matching template in `doc/specs/_templates/`.
